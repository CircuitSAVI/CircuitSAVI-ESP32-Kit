#  Project 14: ESP32 WiFi and BLE Network Analyzer

## 📋 Components Required
- ESP32 Development Board
- USB Data Cable
- Computer with Arduino IDE


##  Direct Wiring Connections

### 1. ESP32 Connection
* Connect the ESP32 directly to your computer using a USB cable. No external circuit wiring is required for standalone signal analysis.


## 🚀 How to Run Code
1. Open [code.ino](code.ino) in Arduino IDE.
2. Ensure default built-in ESP32 libraries (WiFi and BLE) are available.
3. Select Board: ESP32 Dev Module and choose the correct COM Port.
4. Upload the code to ESP32.
5. Open Serial Monitor (115200 Baud) to view live WiFi network scans (SSID, RSSI, channel, security status) and nearby Bluetooth Low Energy devices.
